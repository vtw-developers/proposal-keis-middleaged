중장년내일센터 업무시스템은 고용안정정보망(워크넷)과 웹서비스 방식으로 연계되어 있으며, 구직인증번호, 상담원, 사업자등록번호 조회와 잡케어 서비스 연계를 수행한다. 연계 방식은 HTTPS 기반이며, 업무시스템 관점에서는 필요한 정보를 실시간으로 수신하거나 잡케어 서비스를 송신하는 구조로 운영된다.

| 연계구분 | 연계시스템 | 인터페이스명 | 연계방식 | 송수신 | 연계주기 |
|---|---|---|---|---|---|
| 웹서비스 | 고용안정정보망(워크넷) | 구직인증번호 찾기 | HTTPS | 수신 | 즉시 |

| 웹서비스 | 고용안정정보망(워크넷) | 사업자등록번호 찾기 | HTTPS | 수신 | 즉시 |
| 웹서비스 | 고용안정정보망(워크넷) | 잡케어 서비스 | HTTPS | 송신 | 즉시 |

#### 다. 중장년내일센터 업무시스템 시스템 관계

중장년내일센터 업무시스템은 고용안정정보망(워크넷), 토탈매니저, 고용서비스 성과평가시스템, e-중장년과 연계되어 전직지원, 생애경력지원, 3모작패키지, 기업상담서비스, 센터정보, 사용자 권한정보, 온라인 혼합교육 업무를 처리한다.

워크넷으로부터 구직신청정보와 구인신청정보를 수신하고, 중장년 참여이력을 워크넷으로 송신한다. 토탈매니저와는 사용자정보 및 권한정보를 연계하여 사용자 권한관리를 수행한다. 고용서비스 성과평가시스템과는 사업실적기초자료 및 실적분석정보를 주고받아 전직지원, 생애경력지원, 3모작패키지 실적분석을 지원한다. e-중장년과는 온라인 교육정보 및 교육 신청정보를 연계하여 전직지원·생애경력설계 온라인 교육 업무를 처리한다.

| 연계 대상 | 연계 정보 | 중장년내일센터 관련 업무 |
|---|---|---|
| 고용안정정보망(워크넷) | 구직신청정보, 구인신청정보, 중장년 참여이력 | 전직지원, 생애경력지원, 기업상담서비스 |
| 토탈매니저 | 사용자정보, 권한정보 | 사용자 권한정보 관리 |
| 고용서비스 성과평가시스템 | 사업실적기초자료, 실적 분석정보 | 전직지원 실적분석, 생애경력지원 실적분석, 3모작패키지 실적분석 |
| e-중장년 | 온라인 교육정보, 교육 신청정보 | 전직지원 온라인 교육, 생애경력설계 온라인 교육 |

#### 다. 고용행정통합포털 API 구성

고용행정통합포털 API 구성은 고용24 행정포털을 중심으로 업무 화면, API Gateway, 내부 업무 API, 외부 Legacy API를 연계하는 구조로 구성된다. 사용자는 고용24 행정포털의 업무 메뉴를 통해 서비스를 이용하며, 포털 내 업무 화면은 API Gateway를 통해 고용허가, 직업훈련, 고용복지, 취업지원, 지원금 등 각 영역의 API를 호출한다.

중장년내일센터 업무는 고용24 행정포털 내부의 중장년내일센터 관련 API로 제공되며, 필요 시 WORKNET, 고용보험, HRD-Net, EPS, 취업이룸 등 Legacy API와 연계하여 업무처리에 필요한 외부 정보를 활용한다.

| 구분 | 구성 내용 |
|---|---|
| 사용자 | 고용센터, 시·군·구 등 지자체, 고용노동부 산하기관, 유관기관, 운영기관 담당자 |
| 화면/포털 | 고용24 행정포털 내 업무 메뉴 및 Nexacro 기반 업무화면 |
| API Gateway | 포털 화면과 업무 API 사이의 표준 호출 관문 역할 수행 |
| 포털 업무 API | 취업지원 관련 API, 직업훈련 관련 API, 고용허가 관련 API, 고용복지 관련 API, 지원금 관련 API 등 |
| 중장년 업무 API | 중장년내일센터 업무서비스 기능 제공 |
| 내부 API 서비스 | 고용24 공통 API 서비스, 지원금 API 서비스, 중장년내일센터 API 서비스 |
| Legacy API | WORKNET, 고용보험, HRD-Net, EPS, 취업이룸 등 외부·기존 API 서비스 연계 |

고용행정통합포털 API 구조는 포털 화면과 업무서비스를 분리하고, API Gateway를 통해 표준화된 호출·보안·연계 체계를 적용함으로써 중장년내일센터 업무기능의 재사용성과 확장성을 확보한다.
