## 2.5.x 업무 프로세스 장표 공통 양식 (구역 구분 기준)

본 절(2.5.1 ~ 2.5.6)의 모든 업무 프로세스 장표는 아래 공통 구역 구분을 따른다.
첨부된 `2.5.1 전직지원서비스 업무 프로세스` 장표를 표준 레이아웃으로 사용한다.

### 장표 전체 구역 구성

| 구역 | 명칭 | 위치 | 용도 |
|---|---|---|---|
| A | 헤더 구역 | 최상단 | 장 아이콘, 절 번호, 장표 제목, 사업명 |
| B | 리드 메시지 구역 | 헤더 하단 | 장표 핵심 메시지 1~2줄 (대괄호 강조) |
| C1 | 본문 1 — 주요 처리 흐름 | 상단 본문 | 단계별 가로 프로세스 + 업무주체 영역 바 + 순환·예외 루프 |
| C2 | 본문 2 — 업무주체별 프로세스 | 하단 본문 | 주체 × 단계 매트릭스(스윔레인) |
| D | 푸터 구역 | 최하단 | 프로세스 특징 라벨 박스 + 키포인트 |

### A. 헤더 구역

| 항목 | 내용 |
|---|---|
| 좌측 아이콘 | 장 번호(III) + 장 명칭(기술 및 기능) |
| 상단 라벨 | 2. 기능 요구사항 |
| 장표 제목 | 2.5.x ○○○ 업무 프로세스 |
| 우상단 사업명 | 중장년내일센터 업무시스템 고용24 행정포털 통합 재구축 사업 |

### B. 리드 메시지 구역

- 장표 전체를 한 문장으로 요약 (대괄호로 좌우 강조)
- 핵심 키워드: One-screen, 순환형, 통합 처리, End-to-End 등
- 길이는 2줄 이내로 유지

### C1. 본문 1 — 주요 처리 흐름

| 세부 구역 | 구성 요소 |
|---|---|
| 콘텐츠 제목 바 | ● ○○○ 주요 처리 흐름 + 우측 요구사항 번호 배지(SFR-xxx) |
| 소제목 바 | > 단계별 업무 흐름 |
| 업무주체 영역 바 | 대민 / 센터 담당자 구분 (상단 가로 바) |
| 메인 프로세스 | 번호 원형(①~⑦) + 아이콘 + 단계명 + 한 줄 설명 박스, 좌→우 화살표 |
| 순환·재처리 루프 | 하단 점선 화살표 (보완 요청→재접수 / 추가 상담·훈련 연계 / 재신청 예약) |
| 예외 알림 | ⚠ 박스 (실적 기준 미충족 시 보완 또는 제외 등) |

### C2. 본문 2 — 업무주체별 프로세스

| 세부 구역 | 구성 요소 |
|---|---|
| 소제목 바 | > 업무주체별 프로세스 |
| 헤더 행 | 업무주체 / 단계1 / 단계2 / 단계3 / 단계4 (4~5단계) |
| 주체 행 | 고객 / 운영기관 / 컨설턴트 (3행 권장, 장표에 따라 2~3행) |
| 셀 내용 | 주체별 수행 활동 박스 |
| 연결선 | 행 간 이동(승인·배정·제공·종료 등)은 굵은 화살표로 표시 |

### D. 푸터 구역

| 세부 구역 | 구성 요소 |
|---|---|
| 좌측 라벨 박스 | ○○○ 프로세스 특징 (아이콘 포함, 진한 배경) |
| 우측 키포인트 | ○ 키포인트 1 / ○ 키포인트 2 (2줄, 핵심 메시지) |

### 색상·표현 가이드

- 메인 흐름: 진한 파란색 박스/화살표
- 보조·점선 흐름: 회색 또는 옅은 청록 점선
- 예외/주의: 노란 ⚠ 박스
- 강조 텍스트: 굵은 파란색
- 박스는 동일 크기 유지, 셀 내 문구는 2줄 이내

### 장표별 변동 항목

| 항목 | 변경 여부 | 비고 |
|---|---|---|
| 헤더/푸터 레이아웃 | 고정 | 모든 장표 동일 |
| 요구사항 번호 배지 | 변동 | 장표별 SFR 번호 적용 |
| 메인 프로세스 단계 수 | 변동 | 5~7단계 범위 |
| 업무주체 수 | 변동 | 2~3주체 |
| 순환 루프 개수 | 변동 | 업무 특성 반영 |

## 2.5 중장년 업무서비스 전체 프로세스

### A. 헤더

- 장표 제목: 중장년 업무서비스 전체 프로세스
- 콘텐츠 제목 바: 신청부터 통계까지 End-to-End 업무 흐름
- 요구사항 번호: SFR-001 ~ SFR-014 (중장년 업무서비스 통합)

### B. 리드 메시지

중장년 업무서비스는 신청부터 상담·교육·기업연계·지원금·실적·통계까지 주요 업무가 하나의 흐름으로 연결되는 통합 업무체계로 운영된다.

### C1. 본문 1 — 주요 처리 흐름

#### 중앙 프로세스(7단계)

신청/접수 → 상담·진단 → 서비스 제공 → 교육/기업연계 → 지원금/인센티브 → 실적관리 → 통계·보고

#### 단계별 주요 내용

| 단계 | 주요 내용 |
|---|---|
| 신청/접수 | 대민 신청, 행정 접수, 기본정보 확인 |
| 상담·진단 | 초기상담, 자격 확인, 진단 및 서비스 방향 설정 |
| 서비스 제공 | 전직지원, 생애경력설계, 상담 서비스 운영 |
| 교육/기업연계 | 전직지원교육, 기업서비스, 만남의 날, 동행면접 등 연계 |
| 지원금/인센티브 | 경력지원 사업 지원금, 동행 인센티브 신청 및 지급관리 |
| 실적관리 | 서비스 결과, 교육 결과, 지원금 결과 실적 반영 |
| 통계·보고 | 월간·연간 통계, 보고자료 생성, 의사결정 지원 |

#### 순환·예외 루프

- 본 전체 프로세스 장표에서는 판단, 조건 분기, 예외 흐름, 재처리 루프를 제외한다.
- 세부 분기나 반복 구조는 2.5.1 ~ 2.5.6 개별 프로세스 장표에서 설명한다.

#### 표현 가이드

- 가로형 7단계 프로세스로 단순하게 표현한다.
- 각 단계는 동일 크기 박스로 구성하고, 박스 하단에는 한 줄 설명만 넣어 복잡도를 최소화한다.

### C2. 본문 2 — 업무주체별 프로세스

| 주요 업무 | 주요 업무 흐름 |
|---|---|
| 전직지원서비스 | 신청·승인 → 상담·서비스 제공 → 종료·사후관리 → 실적 반영 |
| 전직지원교육 | 교육프로그램 등록 → 일정/차수 개설 → 신청자·이수자 관리 → 만족도·수료증 관리 |
| 생애경력설계 | 자가진단 → 교육 운영 → 기업출강 → 교육·상담 연계 |
| 기업서비스 | 기업상담 → 적합직무 상담 → 만남의 날·동행면접 → 결과·실적 관리 |
| 직업안정 및 실적관리 | 서비스 결과 수집 → 실적 입력·검증 → 교부결정 → 예산집행 → 정기/수시 집계 |
| 지원금 및 인센티브 지급 | 자격심사 → 지급 신청·검증 → 지원금/인센티브 지급 → 부정청구 모니터링 |

#### 단계별 표시 문구

| 단계 | 표시 문구 |
|---|---|
| 신청/접수 | 대민 신청 · 행정 접수 |
| 상담·진단 | 초기상담 · 자격 확인 |
| 서비스 제공 | 전직지원 · 생애경력설계 |
| 교육/기업연계 | 교육 운영 · 기업연계 |
| 지원금/인센티브 | 지원금 · 인센티브 관리 |
| 실적관리 | 결과 등록 · 실적 반영 |
| 통계·보고 | 통계 집계 · 보고 생성 |

### D. 푸터

#### 프로세스 특징

- 주요 업무별로 분산된 처리 절차를 표준 프로세스 기반으로 통합하여 담당자 업무처리 효율성을 높인다.
- 상담, 교육, 기업서비스, 지원금 지급 결과를 실적·통계·보고와 연계하여 데이터 기반 운영체계를 구현한다.
- 개인 서비스, 기업 서비스, 지원금 업무를 하나의 흐름으로 연결하여 업무 연속성과 추적성을 확보한다.

#### 키포인트

- 신청부터 통계까지 End-to-End 업무 흐름 연결 / 판단·분기 없는 직선형 전체 프로세스 표현
- 주요 업무별 표준 프로세스 정립 / One-stop 업무처리 기반 확보

## 2.5.1 전직지원서비스 운영 프로세스

### A. 헤더

- 장표 제목: 2.5.1 전직지원서비스 업무 프로세스
- 콘텐츠 제목 바: ● 전직지원서비스 주요 처리 흐름 (SFR-003)
- 요구사항 번호: SFR-003 (전직지원서비스 관리기능)

### B. 리드 메시지

전직지원서비스는 대민 신청을 시작으로 센터 담당자의 자격 검토, 승인, 상담, 서비스 제공, 종료·사후관리, 실적 반영까지 이어지는 End-to-End 프로세스로 운영되며, 보완 요청, 추가 상담·훈련 연계, 재신청 예약, 실적 보완·제외가 반복되는 순환형 업무 구조를 가진다.

### C1. 본문 1 — 주요 처리 흐름

#### 업무주체 영역 바

| 영역 | 포함 단계 | 설명 |
|---|---|---|
| 대민 | 1. 신청/접수 | 대민 신청, 보완자료 제출, 재접수 |
| 센터 담당자 | 2. 자격·이력 확인 ~ 7. 실적 반영 | 자격 검토, 승인, 상담, 서비스 제공, 종료·사후관리, 실적 반영 |

#### 메인 프로세스(7단계)

| 단계 | 단계명 | 주요 내용 |
|---|---|---|
| ① | 신청/접수 | 대민 신청, 행정 접수 |
| ② | 자격·이력 확인 | 참여 이력, 상담 이력 확인 |
| ③ | 승인/컨설턴트 배정 | 승인 처리, 담당자 배정 |
| ④ | 상담계획·상담등록 | 상담계획 수립, 상담 등록 |
| ⑤ | 서비스 제공 | 상담 수행, 외부훈련 연계 |
| ⑥ | 종료/사후관리 | 종료 처리, 재신청 예약 |
| ⑦ | 실적 반영 | 실적·통계 연계 |

#### 순환·재처리 루프

| 구분 | 흐름 | 설명 |
|---|---|---|
| 보완 흐름 | ② 자격·이력 확인 → 보완 요청 → 재접수 → ① 신청/접수 | 신청정보 또는 증빙이 미비한 경우 재접수 처리 |
| 상담 반복 흐름 | ⑤ 서비스 제공 → 추가 상담 / 훈련 연계 → ④ 상담계획·상담등록 | 추가 상담 또는 외부훈련 연계가 필요한 경우 반복 수행 |
| 재진입 흐름 | ⑥ 종료/사후관리 → 재신청 예약 → ① 신청/접수 | 종료 후 재신청 예약을 통해 프로세스 재진입 |
| 예외 알림 ⚠ | ⑦ 실적 반영 → 실적 기준 미충족 시 보완 또는 제외 | 실적 인정 기준 미충족 시 보완 후 반영하거나 제외 처리 |

### C2. 본문 2 — 업무주체별 프로세스

| 업무주체 | 신청/접수 | 자격·이력·승인 | 상담·서비스 제공 | 종료·실적 |
|---|---|---|---|---|
| 대민 | 대민 신청 · 행정 접수 | 보완자료 제출 · 재접수 | — | 재신청 예약 |
| 센터 담당자 | — | 참여·상담 이력 확인 · 승인 · 담당자 배정 | 상담계획 수립 · 상담 등록 · 외부훈련 연계 | 종료 처리 · 실적 · 통계 연계 |

### D. 푸터

#### 프로세스 특징

- 대민과 센터 담당자의 업무 경계를 명확히 구분한 2주체 구조

#### 키포인트

- 단순 직선형이 아닌 보완·반복·재진입이 있는 순환형 프로세스 표현
- 신청부터 실적 반영까지 One-stop 업무처리 구조 확보

## 2.5.2 전직지원교육 운영 프로세스

### A. 헤더

- 장표 제목: 2.5.2 전직지원교육 업무 프로세스
- 콘텐츠 제목 바: ● 전직지원교육 주요 처리 흐름 (SFR-004)
- 요구사항 번호: SFR-004 (전직지원서비스교육 관리기능)

### B. 리드 메시지

전직지원교육은 센터 담당자의 교육 개설과 대민 신청을 연결하여 신청자 확정, 출결·이수 관리, 만족도 조사, 수료증·확인증 발급, 실적 반영까지 이어지는 교육 회차 중심 프로세스로 운영한다.

### C1. 본문 1 — 주요 처리 흐름

#### 업무주체 영역 바

| 영역 | 포함 단계 | 설명 |
|---|---|---|
| 센터 담당자 | 교육프로그램 등록, 일정/차수 개설, 출결·이수 관리, 만족도·증명서 관리, 실적 반영 | 교육 운영 전 과정 관리 |
| 대민 | 신청자 접수, 만족도 응답, 수료증·확인증 발급 이용 | 교육 참여 및 사후 응답 |

#### 메인 프로세스(7단계)

| 단계 | 단계명 | 주요 내용 |
|---|---|---|
| ① | 교육프로그램 등록 | 교육프로그램, 과정 기본정보 등록 |

| 만족도 보완 | 만족도 미응답·누락 → 재요청 → 결과 재집계 | 교육·출강 만족도 정합성 확보 |

| 예외 알림 ⚠ | ⑧ 월간/연간 보고 → 수정기간 내 변경 요청 → 보고자료 보정 → 재확정 | 확정 전 보고 품질 보완 |

## 2.5.6 지원금 및 인센티브 지급 프로세스

### A. 헤더

- 장표 제목: 2.5.6 지원금 및 인센티브 지급 업무 프로세스
- 콘텐츠 제목 바: ● 지원금·인센티브 주요 처리 흐름 (SFR-013, SFR-014)
- 요구사항 번호: SFR-013, SFR-014 (지원금/인센티브 지급기능)

### B. 리드 메시지

경력지원 사업 지원금과 동행 인센티브는 참여자·기업의 신청·증빙을 센터 담당자가 자격심사·매칭·지급검증·지급처리·부정청구 점검으로 관리하고, 보완·재검증·차수별 재신청을 반복하는 통제 중심 프로세스로 운영한다.

### C1. 본문 1 — 주요 처리 흐름

#### 업무주체 영역 바

| 영역 | 포함 단계 | 설명 |
|---|---|---|
| 참여자/기업 | 참여 신청, 증빙 제출, 기업 매칭, 만족도 응답 | 신청·증빙·매칭 대상 |
| 센터 담당자 | 자격심사, 매칭, 지급신청 접수, 지급요건 검증 | 지급 대상 및 요건 검토 |
| 지급/점검 | 지급결정, 펌뱅킹, 1차·2차 지급, 부정청구 모니터링, 통계 반영 | 지급 처리 및 감사 대응 |

#### 메인 프로세스(7단계)

| 단계 | 단계명 | 주요 내용 |
|---|---|---|
| ① | 참여자 자격심사 | 참여자·기업·고용상태·사업요건 검토 |
| ② | 참여기업 매칭 | 참여기업 매칭, 지급 대상 확정 |
| ③ | 지급 신청 | 개인지원금, 위탁수수료, 1차·2차 지원금 신청 |
| ④ | 지급요건 검증 | 증빙 확인, 금액·기간·요건 검증 |
| ⑤ | 지급결정/지급처리 | 지급결정, 펌뱅킹, 차수별 지급 처리 |
| ⑥ | 부정청구 모니터링 | 중복 지급, 허위 증빙, 이상 패턴 점검 |
| ⑦ | 만족도·통계 반영 | 만족도, 지급현황, 사업 통계 반영 |

#### 세부 지급 흐름(2종)

| 구분 | 흐름 |
|---|---|
| 경력지원 사업 지원금 | 자격심사 → 참여기업 매칭 → 개인지원금 신청 → 지급결정/펌뱅킹 → 위탁수수료 → 만족도/통계 |
| 동행 인센티브 | 참여자 승인 → 1차 신청·검증 → 1차 지급 → 2차 신청·검증 → 2차 지급 → 부정청구 점검 |

#### 순환·재처리 루프

| 구분 | 흐름 | 설명 |
|---|---|---|
| 자격심사 보완 | ① 자격심사 → 요건 미충족 → 보완 요청 → 재심사 | 참여자·기업·고용상태 요건 보완 |
| 매칭 재조정 | ② 참여기업 매칭 → 조건 불일치 → 재매칭 → 대상 재확정 | 참여기업 조건 조정 |
| 증빙 재검증 | ④ 지급요건 검증 → 증빙 누락·금액 오류 → 보완 → 재검증 | 증빙 정합성 확보 |
| 차수별 재신청 | 1차 지급 → 2차 요건 확인 → 2차 신청·검증 → 2차 지급 | 동행 인센티브 차수별 지급 관리 |
| 지급결과 보완 | ⑤ 지급처리 → 지급 오류·결과 누락 → 결과 확인 → 통계 재반영 | 지급결과 정합성 확보 |
| 예외 알림 ⚠ | ⑥ 부정청구 모니터링 → 이상 패턴 → 지급 보류 → 점검표·조사·반려 | 감사 대응 및 지급 통제 |
