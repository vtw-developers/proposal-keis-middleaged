# 3.2.7 요구사항별 구현방안 최종 장표 구성안

## 1. 최종 검토 결과

3.2.7 요구사항별 구현방안은 기존 37장 구성에서 **총 35장 구성**으로 조정합니다.

기존 37장 구성은 기능 누락 방지에는 유리하지만, 제안요청서 관점에서는 기능 화면 나열형으로 보일 수 있습니다. 최종안은 고용24 공통서비스, EDMS, UI 표준, 인터페이스, 데이터 표준, 개인정보 접속기록, 리포팅, 업무서비스/API 전환 구조를 먼저 제시하고, 이후 SFR-002부터 SFR-015까지 요구사항별 TO-BE 화면과 프로세스·개념도를 배치하는 방식으로 구성합니다.

| 구분 | 기존안 | 최종안 | 검토 결과 |
|---|---:|---:|---|
| 전체 장표 수 | 37장 | 35장 | 변경 권장 |
| 공통 구현 원칙 | 약함 | 공통 선행 2장 추가 | RFP 대응력 강화 |
| SFR-003 전직지원서비스 | 5장 | 5장 유지 | 핵심 업무이므로 유지 |
| SFR-004 전직지원교육 | 3장 | 2장으로 병합 | 교육 생애주기 화면으로 통합 |
| SFR-006 생애경력설계교육 | 3장 | 2장으로 병합 | 전직지원교육과 유사 패턴 |
| SFR-008 기업서비스 | 3장 | 2장으로 병합 | 기업상담·적합직무 상담 패턴 통합 |
| SFR-015 DW 통계 | 2장 | 1장으로 병합 | 데이터 연계 구조 중심 |
| 지원금/인센티브 | 각 3장 | 각 3장 유지 | 심사·지급·펌뱅킹·부정청구 통제 중요 |
