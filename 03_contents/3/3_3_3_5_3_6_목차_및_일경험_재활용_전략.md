# 3.3 유지관리 수행 요구사항 / 3.5 보안 요구사항 / 3.6 제약사항 목차 및 일경험 재활용 전략

## 1. 검토 결론

일경험 제안서의 **유지관리 수행 요구사항, 보안 요구사항, 제약사항** 장표는 목차 골격과 장표 표현 방식은 재활용 가능함.

다만 현재 사업은 **중장년내일센터 업무시스템을 고용24 행정포털로 통합 재구축**하는 사업이므로, 다음 내용을 현 사업 특화 요소로 보강해야 함.

- 고용24 대민포털/행정포털 기존 기능의 연속 운영
- 계약체결 시점까지 운영 중인 기능의 개선사항 반영
- 중장년내일센터 및 중장년경력지원 서비스 현행화
- 고용24 공통서비스, EDMS, 개인정보 접속기록, 클라우드/PaaS 보안 반영
- 웹접근성, 웹품질, 웹취약점, 표준프레임워크, 개발언어, 법적 제약 준수
- 기존 시스템 호환성, 변경사항 반영, 하자담보, 참조모델 활용 조건 대응

## 3.3.3 유지관리 작성 우선순위

### 1순위: 반드시 강조

- 기존 운영 기능 중단 방지
- 계약체결 시점 운영 중 기능까지 반영
- SR 기반 개선사항 접수·영향분석·개선·테스트·운영반영
- 고용24 공통 적용에 따른 변경 영향도 관리
- 데이터 전환/EDMS 이관 이후 오류 및 데이터 정합성 대응

### 2순위: 기본기 확보

- 수리/완전/예방/적응 유지관리 유형 구분
- 운영문서 및 산출물 현행화
- 웹접근성, 웹품질, 웹취약점 진단 결과 조치
- 배치프로그램 오류 개선

### 3순위: 보완 설명

- 정기/비정기 예방점검
- 사용자 교육 지원
- 성능 분석 및 튜닝
- 데이터 품질·표준 관리 지원
