# 3.2.7 요구사항별 구현방안 주요화면 장표 구성안

## 구성 기준

- `3.2.7.x`는 요구사항/기능군 단위의 장표 제목으로 사용한다.
- 각 기능군 안에서는 `1, 2, 3` 형식으로 주요화면 순번을 부여한다.
- 목차별 상세 장표는 최대 6개 이내로 제한한다.
- 모든 세부 화면을 나열하지 않고, 업무 흐름상 핵심 화면만 선정한다.
- 장표당 화면 예시는 1~2개를 기준으로 한다.
- 한 화면으로 충분히 설명되는 경우는 1개 화면만 배치하고, 업무 흐름상 비교·연계가 필요한 경우는 2개 화면을 함께 배치한다.
- 조회, 파일받기, 일괄처리, 승인, 삭제, 발송 등 보조 기능은 하단 주요 기능 문구로 흡수한다.
- 상단 설명 문구는 장표 메시지 역할로 2문장 내외로 구성한다.
- 하단 주요 기능 문구는 구현 포인트 3개 내외로 구성한다.

- 하나의 대표 화면으로 설명 가능한 장표는 1개만 배치한다.
- 업무 흐름이나 비교 관계를 보여줘야 하는 장표는 2개 화면을 배치한다.
- 장표 하단 주요 기능에는 화면에 담지 못한 세부 기능을 3개 내외로 정리한다.
- 참조표에서는 각 장표와 SFR 요구사항 번호를 매핑한다.
