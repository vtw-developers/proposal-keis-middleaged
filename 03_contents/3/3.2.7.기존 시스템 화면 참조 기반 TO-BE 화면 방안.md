# 기존 시스템 화면 참조 기반 TO-BE 화면 방안

## 1. 정리 방향

기존 중장년내일센터 업무화면은 업무 절차, 입력항목, 사용자 조작 흐름을 식별하기 위한 참조자료로 활용한다. TO-BE 화면은 고용24 행정포털 표준 UI와 공통서비스를 적용하여 목록·상세·처리·이력 중심의 일관된 화면체계로 재설계한다.

업무 흐름이 안정적이고 요구사항과 정합성이 높은 목록/등록 화면은 구조를 유지하되, 고용24 공통 컴포넌트, 접근성, 권한, 개인정보 접속기록, EDMS, SMS/E-mail, 리포팅 연계를 반영하여 개선한다.

---

## 2. TO-BE 화면 설계 판단 기준

| 구분 | 판단 기준 | 적용 방식 |
|---|---|---|
| 유지 | 업무 흐름이 명확하고 기존 목록/등록/수정 구조가 요구사항과 거의 일치하는 화면 | 화면 구조는 유지하되 고용24 스타일, 공통 버튼, 검색조건, 그리드, 접근성, 권한, 접속기록 적용 |
| 개선 | 기능은 유지하지만 화면이 복잡하거나 여러 기능이 분산되어 담당자 조작 단계가 많은 화면 | 탭, 아코디언, 상세 패널, 업무상태 표시, 일괄처리 버튼으로 재배치 |
| 통합 | 유사 메뉴가 중복되거나 공통서비스로 대체 가능한 화면 | SMS/E-mail, 첨부파일, 상담, 권한, 접속기록, 통계 다운로드 기능은 공통서비스 연계 중심으로 통합 |
| 신규 | 기존 화면이 없거나 RFP에서 신규 업무로 요구한 기능 | TO-BE 목업 신규 작성 |

## 4. 기존 화면 유지 가능 영역

아래 화면들은 업무 구조 자체는 유지해도 무방하다. 다만 그대로 복사하는 것이 아니라 고용24 표준 UI와 공통서비스를 적용한 후 유지하는 방식으로 표현한다.

| 기존 화면 | 유지 판단 | TO-BE 반영 조건 |

## 6. 장표 메시지 예시

### 기존 화면 참조 및 TO-BE 재설계 방향

기존 중장년내일센터 업무화면은 업무 절차, 입력항목, 사용자 조작 흐름을 식별하기 위한 참조자료로 활용합니다. TO-BE 화면은 고용24 행정포털 표준 UI와 공통서비스를 적용하여 목록·상세·처리·이력 중심의 일관된 화면체계로 재설계합니다. 업무 흐름이 안정적이고 요구사항과 정합성이 높은 목록/등록 화면은 구조를 유지하되, 고용24 공통 컴포넌트, 접근성, 권한, 개인정보 접속기록, EDMS, SMS/E-mail, 리포팅 연계를 반영하여 개선합니다.

### 유지/개선/통합/신규 적용 기준

단순 조회·등록·출력 중심의 기존 화면은 유지하고, 고객·상담·교육·통계처럼 다수 기능이 분산된 화면은 탭형 상세와 업무상태 기반 화면으로 개선합니다. SMS/E-mail, 첨부파일, 상담이력, 권한, 개인정보 접속기록은 개별 화면별 구현이 아니라 고용24 공통서비스 연계로 통합합니다. 나의 할 일, 자가진단, 지원금, 인센티브, DW 통계 등 기존 화면이 없거나 신규 업무인 영역은 TO-BE 목업을 신규 설계합니다.

## 7. 제안서 작성 시 표현 원칙

- “기존 화면 유지”라고 단정하지 않고 “업무 구조는 유지하되 고용24 표준 UI와 공통서비스를 적용하여 개선”으로 표현한다.
- 화면 예시는 기존 화면을 그대로 캡처하지 않고, TO-BE 목업 또는 개선 방향이 드러나는 재구성 화면으로 표현한다.
- 기능 범위가 넓은 장표는 화면만 나열하지 않고, 업무 프로세스 또는 개념도와 함께 배치한다.
- 개인정보, 권한, 첨부파일, SMS/E-mail, 리포팅, 통계 다운로드는 공통서비스 또는 공통 컴포넌트 적용 항목으로 별도 표시한다.
- 기존 화면이 없는 요구사항은 신규 목업 대상으로 명확히 구분한다.
